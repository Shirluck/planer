# Журнал изменений

Все заметные изменения Планера. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [семантические](https://semver.org/lang/ru/): `ОСНОВНАЯ.НОВОЕ.ИСПРАВЛЕНИЕ`.

Раздел вышедшей версии становится текстом релиза на GitHub (`npm run release`).
Новые изменения записывайте в «Не выпущено», при выпуске переименуйте его в номер версии.

## [Не выпущено]

## [2.5.0] — 2026-11-18

### Добавлено
- **Таймеры для фокусировки**: кнопка в левом углу шапки, готовые шаблоны (Фокус 25 мин, перерывы, Глубокая работа),
  свои таймеры любой длительности, пауза, +1 минута, несколько таймеров сразу. В конце — звук, сообщение и уведомление.
  Отсчёт идёт в основном процессе, поэтому он точный и в трее.
- **Поиск по всему (`Ctrl+K`)**: задачи за все дни и заметки к ним, страницы, папки, карточки досок; переход к найденному,
  ввод даты, быстрые действия.
- **Мини-окно «Сегодня»** по щелчку на значок в трее: отметки, новая задача, таймеры.
- **Оформление**: тема (как в системе / светлая / тёмная), размер интерфейса 80–150 %, компактный режим.
- **Рисование от руки прямо на доске**: перо, маркер, ластик, 6 цветов, 3 толщины; штрихи собираются в карточку-рисунок.
- **Восстановление из резервных копий** с просмотром отличий и отменой; копия вручную.
- **Автозапуск вместе с Windows** сразу в трей.
- Проверка типов (`npm run typecheck`), модульные тесты (`npm run test:unit`), проверка собранного exe (`scripts/packaged-check.js`).

### Изменено
- Код главного окна разнесён по файлам `src/app/*.js`, чистая логика — `src/core.js`, цвета тем — `src/tokens.css`.
- CSP без `'unsafe-inline'` для скриптов.
- Ежедневная резервная копия делается, даже если программа неделями работает в трее.
- Установщик меньше примерно на 8 МБ: только русская и английская локали Chromium.

### Безопасность
- Electron fuses: без запуска как Node.js, без `NODE_OPTIONS` и `--inspect`; код только из `app.asar` с проверкой целостности.

## [2.4.0] — 2026-11-17

### Добавлено
- ИИ-ассистент через подписку Claude (Claude Code на этом компьютере) — без ключа API; окно «Ассистент: подключение».

## [2.3.0] — 2026-11-17

### Добавлено
- Превью ссылок на доске: заголовок, описание, картинка, обложки YouTube.
- Файлы в «Основных планах» и «Идеях» бывают двух видов — текст или доска; открываются двойным щелчком.
- Работа в трее: крестик и «Свернуть» убирают окно к часам.

## [2.2.0] — 2026-11-17

### Добавлено
- Перетаскивание задач мышью между днями, блоками и местами в списке.
- Блоки времени дня (например, 10:00–12:00 «Работа»).

## [2.1.0] — 2026-11-17

### Изменено
- «Неделя» стала календарём по дням (в обзоре — только срочное), «Сегодня» показывает план на сегодняшнюю дату.
- Доски принадлежат страницам «Основных планов» и «Идей».

## [2.0.0] — 2026-11-17

### Добавлено
- Настольное приложение на Electron: доски в стиле Milanote (заметки, чек-листы, фото, видео, зарисовки, ссылки),
  медиа-хранилище, редактор зарисовок, ассистент с инструментами для досок.
- Установщик и portable-версия для Windows, автотесты.
