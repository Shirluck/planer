# Планер: десктопное приложение

Четыре колонки: **Сегодня** (план на сегодняшний день), **Неделя** (календарь: каждый день расписывается отдельно,
на обзоре — только срочное), **Основные планы** и **Идеи** (папки и страницы, у каждой страницы — **доска** в духе Milanote:
заметки, чек-листы, фото, видео, зарисовки и ссылки). Плюс ИИ-ассистент.
Всё хранится локально, без аккаунтов. Интернет нужен только ассистенту.

## Установка готовой программы (Windows 10/11 x64)

В папке `dist/` после сборки лежат два файла:

- `Planer-Setup-<версия>.exe` — установщик. Ставится для текущего пользователя, права администратора не нужны,
  можно выбрать папку, создаются ярлыки на рабочем столе и в меню «Пуск». Языки установщика: русский и английский.
  Удаление — через «Параметры → Приложения» или «Программы и компоненты».
- `Planer-<версия>-portable.exe` — одна программа без установки, запускается двойным щелчком.

Программа не подписана сертификатом, поэтому при первом запуске Windows SmartScreen может показать
«Система Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.
Если файл скачан из интернета и не запускается, откройте его «Свойства» и отметьте «Разблокировать».

## Запуск из исходников

1. Установите Node.js (LTS): https://nodejs.org
2. В папке проекта:

```
npm install
npm start
```

## Сборка

```
npm run dist       # установщик и portable: dist/Planer-Setup-<версия>.exe, dist/Planer-<версия>-portable.exe
npm run dist:dir   # быстрая распакованная сборка для проверки: dist/win-unpacked/Planer.exe
npm run icons      # пересоздать build/icon.png и build/icon.ico
```

Собирать нужно на той системе, для которой делается сборка (на macOS — `.dmg`, на Linux — `.AppImage`).
Версия берётся из `package.json` и видна в меню «Справка → О программе» (на Windows меню скрыто — нажмите Alt).

## Проверки

```
npm test                 # автотесты Playwright для Electron (≈1 мин), скриншоты пишутся в tests/screens/
npm run dist:dir
npm run test:packaged    # сквозной тест собранного dist/win-unpacked/Planer.exe
```

Тесты используют временные папки данных (переменная `PLANER_DATA_DIR`) и не трогают ваши настоящие данные.
Тестовые файлы (картинки, короткое видео WebM) генерируются автоматически в `tests/.fixtures/`.
Чтобы прогнать сквозной тест на установленной программе: `PLANER_EXE=<путь к Planer.exe> npm run test:packaged`.

## Сегодня и Неделя (календарь)

Каждая задача относится к конкретному дню (или лежит в «Без даты»).

- **Сегодня** — задачи сегодняшней даты: то, что вы расписали на этот день во «Неделе», плюс то, что добавили прямо здесь.
  Если в прошлые дни остались невыполненные задачи, внизу появится блок «Не сделано в прошлые дни»:
  каждую можно перенести на сегодня кнопкой со стрелкой (или все сразу). После полуночи колонка сама переходит на новый день.
- **Неделя** — календарь месяца (листайте месяцы стрелками ‹ ›) и под ним дни выбранной недели (‹ › — соседние недели).
  На обзоре видны **только срочные задачи** — с приоритетом `!!!`; у остальных дней показано, сколько там задач.
  Кнопка с флажком переключает «только срочные / все задачи», кнопка с календарём прячет сетку месяца,
  кнопка с солнцем возвращает к текущей неделе. Точка под числом — в этот день есть задачи, красная — есть срочные.
- **Щелчок по дню** (в сетке месяца или в списке недели) открывает окно дня со всеми задачами: их можно добавлять,
  менять, отмечать, менять порядок перетаскиванием. `Alt+←` / `Alt+→` — соседние дни, `Esc` — закрыть.
- Срочность задаётся флажком приоритета (щелчок перебирает `!` → `!!` → `!!!`) или `!!!` в конце текста новой задачи.
- Перенос задачи: меню `…` → «на сегодня», «на завтра», «на другой день…» (выбор в календаре) или «убрать дату».
  Задачу можно перетащить за ручку слева на день недели или на число в календаре. Любой перенос можно отменить.

## Доска страницы

Доски живут у страниц в колонках **«Основные планы»** и **«Идеи»**: значок холста в строке страницы
(виден при наведении, а если на доске что-то есть — всегда, с числом карточек), кнопка «Доска» в редакторе страницы
или пункт «Открыть доску» в меню страницы.

Слева — панель добавления: **Заметка, Чек-лист, Фото / видео, Зарисовка, Ссылка**. Ещё способы:
двойной щелчок по пустому месту (заметка), перетаскивание файлов из проводника (карточка появится там, куда бросили;
несколько файлов раскладываются сеткой), `Ctrl+V` (скриншот, скопированная картинка, ссылка или текст).

В заметках: `**жирный**`, строка с `- ` — список, `[ ] ` — чекбокс (отмечается щелчком прямо на доске).
Панель форматирования и цвета появляется сверху, пока заметка редактируется.

### Горячие клавиши доски

| Действие | Клавиши |
|---|---|
| Перемещение холста | перетаскивание пустого места, `Пробел` + мышь, средняя кнопка, колесо / тачпад |
| Масштаб | `Ctrl` + колесо, `+` / `−`, `Shift+0` — 100 %, `Shift+1` — показать всё |
| Рамка выделения | `Shift` + перетаскивание (добавить к выделению) или `Ctrl` + перетаскивание |
| Выделить несколько / всё | `Shift` + щелчок, `Ctrl+A` |
| Редактировать | двойной щелчок, щелчок по выделенной заметке, `Enter` |
| Новая заметка | двойной щелчок по пустому месту, `N` |
| Удалить | `Delete` / `Backspace` (можно отменить) |
| Дублировать | `Ctrl+D` |
| Копировать / вырезать / вставить | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` (или `Ctrl+Y`), до 100 шагов |
| Сдвинуть выделенное | стрелки (10 px), `Shift` + стрелки (1 px) |
| Закрыть доску / выйти из редактирования | `Esc` или щелчок по затемнённому фону |

Правый щелчок по карточке — меню: цвет, слои (на передний/задний план), подпись, «Нарисовать поверх»,
«Сохранить как…» (PNG), «Копировать в буфер», «Открыть во внешнем плеере» (для видео).
Двойной щелчок по фото — просмотр во весь экран (колесо — масштаб, `←` `→` — соседние фото, `0` — вписать).

### Зарисовки

Инструменты: перо (с нажимом пера/стилуса), маркер, ластик (по штрихам или «по пикселям»), линия, стрелка,
прямоугольник, эллипс, текст, пипетка. Фон: прозрачный, белый, клетка, линейка.
Клавиши: `P` `M` `E` `L` `A` `R` `O` `T` `I` — инструменты, `[` `]` — толщина, `Shift` — ровные линии и фигуры,
`Ctrl+Z` / `Ctrl+Shift+Z`, `Пробел` или средняя кнопка — перемещение, `Ctrl` + колесо — масштаб.
`Esc` или «Готово» — сохранить и закрыть, «Отмена» — закрыть без изменений.
Рисунок поверх фото хранится отдельным слоем: оригинал не меняется, слой можно убрать в меню карточки.

### Поддерживаемые форматы

- Изображения: PNG, JPG/JPEG, WEBP, GIF (анимация сохраняется), AVIF, SVG.
- Видео: MP4 (H.264), WEBM, MOV, MKV. Если кодек не поддерживается встроенным плеером (например, HEVC/H.265
  на некоторых компьютерах), карточка покажет сообщение и кнопку «Открыть во внешнем плеере».
- Предел одного файла — 2 ГБ; для файлов больше 200 МБ показывается прогресс копирования.
- HEIC/HEIF не поддерживается (сохраните фото как JPG).

## Где что лежит

Кратко: **программа** — в `%LOCALAPPDATA%\Programs\Planer\` (или там, где лежит portable-файл),
**ваши данные** — в `%APPDATA%\Planer\`, **исходники и сборки** — в папке проекта.

### 1. Установленная программа (после `Planer-Setup-<версия>.exe`)

| Что | Где (по умолчанию) |
|---|---|
| Папка программы | `%LOCALAPPDATA%\Programs\Planer\` (например, `C:\Users\<имя>\AppData\Local\Programs\Planer\`); если при установке выбрана другая папка — там |
| Запускаемый файл | `…\Planer\Planer.exe` |
| Код приложения (упакован) | `…\Planer\resources\app.asar` |
| Удаление программы | `…\Planer\Uninstall Planer.exe` (или «Параметры → Приложения») |
| Ярлык на рабочем столе | `Рабочий стол\Планер.lnk` |
| Ярлык в меню «Пуск» | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Планер.lnk` |
| Запись для «Программы и компоненты» | реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<GUID>` |

Установщик ставит программу только для текущего пользователя, в системные папки (`Program Files`) ничего не пишет.
При удалении стираются папка программы, ярлыки и запись в реестре; **данные в `%APPDATA%\Planer\` остаются**
(чтобы удалить всё, сотрите эту папку вручную при закрытой программе).

### 2. Portable-версия (`Planer-<версия>-portable.exe`)

Один файл, лежит там, куда вы его положили. При каждом запуске он распаковывается во временную папку
`%TEMP%\<служебное имя>\` и удаляет её после выхода. Данные хранит **в той же папке `%APPDATA%\Planer\`**,
что и установленная версия, поэтому одновременно может работать только одна из них.

### 3. Ваши данные

- Windows: `%APPDATA%\Planer\` (например, `C:\Users\<имя>\AppData\Roaming\Planer\`)
- macOS: `~/Library/Application Support/Planer/`
- Linux: `~/.config/Planer/`

```
Planer\
├─ docs\                                   документы (каждый — отдельный JSON, запись атомарная)
│  ├─ data__users__local__planner-cal.json     задачи по датам («Сегодня» и «Неделя») и «Без даты»
│  ├─ data__users__local__planner-plans.json   «Основные планы» (папки и страницы)
│  ├─ data__users__local__planner-ideas.json   «Идеи»
│  ├─ data__users__local__board-<id>.json      доска страницы (карточки и ссылки на медиа)
│  └─ …planner-day.json, …planner-week.json    списки версии 1 (после переноса в календарь не используются и не удаляются)
├─ media\                                  фото, видео, готовые зарисовки: <sha256>.<расширение>
│  ├─ thumbs\                              миниатюры и постеры видео
│  ├─ vectors\                             штрихи зарисовок (для повторного редактирования)
│  └─ index.json                           служебный список медиа (дата последнего использования)
├─ backups\
│  ├─ docs-ГГГГ-ММ-ДД\                     ежедневная копия всех документов (хранятся 14 последних)
│  ├─ planner-data-before-schema-2-….json  копия старого файла, сделанная перед переходом на новый формат
│  └─ deleted\                             документы, удалённые через программу
├─ planer-meta.json                        версия формата данных (schema)
├─ api-key.bin                             ключ API Anthropic (зашифрован средствами Windows)
├─ planner-data.json                       старый файл версии 1 (если был; после импорта не используется и не удаляется)
└─ Cache\, Code Cache\, GPUCache\, Local Storage\, Preferences, Local State, …   служебные файлы Chromium/Electron
```

- Повреждённый файл не удаляется, а переименовывается рядом в `<имя>.json.corrupt-<дата>`; программа сообщит об этом.
- Служебные папки Chromium можно удалять только при закрытой программе; ваших записей в них нет
  (в `Local Storage` — только настройки редактора зарисовок: последний инструмент, цвет, толщина).
- Быстро открыть папку: меню «Данные → Открыть папку с данными» (или «…с резервными копиями»).
- Чтобы перенести всё на другой компьютер, скопируйте папку `Planer` целиком (при закрытой программе).

### 4. Исходники и сборка (папка проекта)

| Что | Где |
|---|---|
| Приложение | `index.html` (колонки, страницы, ассистент), `src/board.js`, `src/board.css` (доска), `src/sketch.js` (зарисовки) |
| Основной процесс | `main.js` (окно, меню, ключ, API), `lib/store.js` (документы, миграция, копии), `lib/media.js` (медиа, `media://`, сборка мусора) |
| Мост и прослойка | `preload.js`, `shim.js` |
| Иконка | `build/icon.png`, `build/icon.ico` (создаются `scripts/make-icon.js`) |
| Настройки сборки | `package.json` (раздел `build`) |
| Автотесты | `tests/*.spec.js`, `playwright.config.js`; скриншоты — `tests/screens/`, тестовые файлы — `tests/.fixtures/`, отчёты об ошибках — `test-results/` |
| Готовые сборки | `dist/Planer-Setup-<версия>.exe`, `dist/Planer-<версия>-portable.exe`, распакованная — `dist/win-unpacked/Planer.exe` |
| Зависимости разработки | `node_modules/` (не нужны для работы готовой программы) |
| Кэши загрузок | `%LOCALAPPDATA%\electron\Cache\` (Electron), `%LOCALAPPDATA%\electron-builder\Cache\` (NSIS и инструменты сборки) |

Автотесты создают временные папки данных `%TEMP%\planer-*` и удаляют их после себя;
настоящую папку `%APPDATA%\Planer\` они не трогают.

При переходе на календарь задачи старой колонки «Сегодня» попадают на сегодняшнюю дату, задачи старой «Недели» — в «Без даты»
(видны внизу колонки «Неделя»), а доски, которые были у задач, становятся страницами в «Основных планах → Доски задач».

Старый файл `planner-data.json` (версия 1) при первом запуске новой версии импортируется автоматически,
его копия кладётся в `backups/`, сам файл не удаляется.

Удалённые с доски файлы стираются с диска не сразу: только если на них больше нет ссылок ни в одной доске
и ни в одной резервной копии и прошло 7 дней (чтобы работала отмена удаления).

## ИИ-ассистент

При первом обращении приложение попросит ключ API Anthropic (создать: https://console.anthropic.com/settings/keys).
Ключ хранится только на этом компьютере и уходит только на api.anthropic.com из основного процесса.
Сменить или удалить ключ: меню «Ассистент».

Ассистент видит календарь (сегодня, неделю назад и 4 недели вперёд, «Без даты») и умеет добавлять задачи на любой день,
менять их, переносить между днями и удалять (удаляет только по прямой просьбе), читать и создавать страницы,
**читать доски страниц** и **добавлять на них заметки и чек-листы** (в свободное место).
Картинки с досок он видит только когда вы прямо просите посмотреть: изображение уменьшается до 1568 px и
отправляется в формате JPEG; в чате видно, какие картинки отправлены. Модели задаются в `shim.js` (`MODELS`).

## Из чего состоит

- `index.html` — основное приложение (колонки, страницы, ассистент); тот же код работает и в версии в Claude.
- `src/board.js`, `src/board.css` — доска страницы; `src/sketch.js` — редактор зарисовок.
- `shim.js` — подменяет хранилище и ИИ-часть на локальные.
- `main.js` — окно, меню, ключ, запросы к API; `lib/store.js` — документы, миграция, копии;
  `lib/media.js` — медиа, схема `media://`, миниатюры, сборка мусора; `preload.js` — мост к странице.
- `tests/` — автотесты Playwright, `scripts/make-icon.js` — генерация иконки.

## Известные ограничения

- Превью страниц для ссылок не загружаются (никаких сетевых запросов, кроме ассистента): карточка показывает домен.
- Доска удалённой страницы не стирается: её файл остаётся в `docs/` (это позволяет отменить удаление),
  а медиа с такой доски не стираются автоматически.
- Блок «Не сделано в прошлые дни» охватывает последние 60 дней; более старые задачи остаются на своих датах в календаре.
- Видео с HEVC и некоторыми другими кодеками может не воспроизводиться встроенным плеером — используйте внешний.
- Анимированный GIF на доске показывается оригиналом (без уменьшенной копии).
- Один экземпляр программы на одну папку данных; синхронизации между компьютерами нет.
- Установщик и программа не подписаны (предупреждение SmartScreen при первом запуске).
