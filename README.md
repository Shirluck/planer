# Планер: десктопное приложение

Четыре колонки (Сегодня, Неделя, Основные планы, Идеи) + ИИ-ассистент.
Работает на Windows, macOS и Linux. Данные хранятся в файле на вашем компьютере, интернет нужен только ассистенту.

## Запуск

1. Установите Node.js (версия LTS): https://nodejs.org
2. Откройте терминал в этой папке и выполните:

```
npm install
npm start
```

## Установщик (чтобы запускать как обычную программу)

```
npm run dist
```

Готовый файл появится в папке `dist/` (на Windows `.exe`, на macOS `.dmg`, на Linux `.AppImage`).
Собирать нужно на той системе, для которой делаете установщик.
Приложение не подписано, поэтому Windows и macOS могут показать предупреждение при первом запуске:
на Windows «Подробнее → Выполнить в любом случае», на macOS правый клик → «Открыть».

## ИИ-ассистент

При первом обращении к ассистенту приложение попросит ключ API Anthropic (создать: https://console.anthropic.com/settings/keys).
Ключ хранится только на этом компьютере (шифруется средствами системы, если они доступны) и уходит только на api.anthropic.com.
Использование оплачивается по тарифам API. Без ключа всё остальное работает.
Сменить или удалить ключ: меню «Ассистент» (на Windows и Linux меню скрыто, нажмите Alt).

Ассистент умеет добавлять, менять, переносить и удалять задачи (удаляет только по прямой просьбе), читать и создавать страницы.
Какая модель используется, задаётся в `shim.js` (объект `MODELS`).

## Где лежат данные

- Windows: `%APPDATA%\Planer\planner-data.json`
- macOS: `~/Library/Application Support/Planer/planner-data.json`
- Linux: `~/.config/Planer/planner-data.json`

Раз в день автоматически делается копия в подпапку `backups/` (хранятся последние 14).
Быстро открыть папку: меню «Данные → Показать файл с данными».
Чтобы перенести данные на другой компьютер, скопируйте файл `planner-data.json`.

## Из чего состоит

- `index.html` — само приложение (тот же код, что и в версии в Claude)
- `shim.js` — подменяет хранилище и ИИ-часть на локальные
- `main.js`, `preload.js` — оболочка Electron: окно, файл данных, ключ, запросы к API
