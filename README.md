**Скачать для Windows:** [последний выпуск](https://github.com/Shirluck/planer/releases/latest) —
`Planer-Setup-<версия>.exe` (установщик) или `Planer-<версия>-portable.exe` (без установки).
Что нового — в [CHANGELOG.md](CHANGELOG.md).

Четыре колонки: **Сегодня** (план на сегодняшний день), **Неделя** (календарь: каждый день расписывается отдельно,
на обзоре — только срочное), **Основные планы** и **Идеи** (папки и страницы, у каждой страницы — **доска** в духе Milanote:
заметки, чек-листы, фото, видео, зарисовки, ссылки и рисунки от руки, с выравниванием и направляющими),
текстовые страницы **как в Notion** (блоки, «/», Markdown). Плюс ИИ-ассистент, который умеет и наводить порядок на досках,
**таймеры для фокусировки**, **инструменты моушн-дизайнера** (ссылки, экспрешены After Effects, тайминг),
**поиск по всему** (`Ctrl+K`), **мини-окно «Сегодня»** из трея, темы оформления и **восстановление из резервных копий**.
Всё хранится локально, без аккаунтов. Интернет нужен только ассистенту и превью ссылок.

## Установка готовой программы (Windows 10/11 x64)

В папке `dist/` после сборки лежат два файла:

- `Planer-Setup-<версия>.exe` — установщик. Ставится для текущего пользователя, права администратора не нужны,
  можно выбрать папку, создаются ярлыки на рабочем столе и в меню «Пуск». Языки установщика: русский и английский.
  Удаление — через «Параметры → Приложения» или «Программы и компоненты».
- `Planer-<версия>-portable.exe` — одна программа без установки, запускается двойным щелчком.

Программа не подписана сертификатом, поэтому при первом запуске Windows SmartScreen может показать
«Система Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.
Если файл скачан из интернета и не запускается, откройте его «Свойства» и отметьте «Разблокировать».

### Работа в трее

Крестик и «Свернуть» не закрывают программу, а убирают окно в трей (значок у часов; если его не видно — стрелка «^»).
Перед этим все изменения записываются на диск.

- **Щелчок по значку** — мини-окно «Сегодня» (см. ниже); **двойной щелчок** или пункт «Открыть Планер» — всё приложение.
- **Правый щелчок** — меню: «Сегодня…», запуск таймера, остановка таймеров, «Запускать вместе с Windows», «Выйти из Планера».
- При наведении на значок видно, сколько осталось у идущего таймера.
- Закрыть полностью — **правый щелчок по значку → «Выйти из Планера»** (или меню «Справка → Выйти из Планера», `Ctrl+Q`).

### Мини-окно «Сегодня»

Маленькое окно у часов со списком дел на сегодня (по блокам времени, срочные отмечены): отметить выполненное,
добавить задачу (`!!!` в конце — срочно), запустить таймер, а щелчок по задаче открывает её в Планере.
Всё сразу сохраняется и видно в главном окне. Окно прячется, когда щёлкаете в другом месте, или по `Esc`.

### Автозапуск

«Настройки» (шестерёнка в шапке) → «Запускать вместе с Windows», или тот же пункт в меню значка в трее.
Планер стартует свёрнутым в трей, без окна. Для portable-версии автозапуск указывает на сам файл — не перемещайте его.

## Запуск из исходников

1. Установите Node.js (LTS): https://nodejs.org
2. В папке проекта:

```
npm install
npm start
```

## Сборка

```
npm run dist       # установщик и portable: dist/Planer-Setup-<версия>.exe, dist/Planer-<версия>-portable.exe
npm run dist:dir   # быстрая распакованная сборка для проверки: dist/win-unpacked/Planer.exe
npm run icons      # пересоздать build/icon.png и build/icon.ico
```

Собирать нужно на той системе, для которой делается сборка (на macOS — `.dmg`, на Linux — `.AppImage`).
Версия берётся из `package.json` и видна в меню «Справка → О программе» (на Windows меню скрыто — нажмите Alt).

## Выпуск новой версии на GitHub

Нужен один раз: GitHub CLI и вход в него (`winget install --id GitHub.cli`, затем `gh auth login --web --scopes workflow`).

1. Внесите изменения и закоммитьте их в ветку `main` (`git add -A`, `git commit -m "feat: …"`).
   Что нового — допишите в раздел «Не выпущено» в [CHANGELOG.md](CHANGELOG.md). Если оставить его пустым,
   в описание версии попадут темы коммитов.
2. Выпустите версию одной командой:

```
npm run release -- minor    # новые возможности: 2.5.0 → 2.6.0
npm run release -- patch    # только исправления: 2.5.0 → 2.5.1
npm run release -- major    # большие изменения: 2.5.0 → 3.0.0
```

Скрипт `scripts/release.js` сам:

- проверит, что всё закоммичено и вход в GitHub выполнен;
- поднимет номер версии в `package.json` и перенесёт «Не выпущено» в раздел новой версии CHANGELOG;
- прогонит все тесты, соберёт установщик и portable-версию и проверит собранную программу;
- сделает коммит `chore(release): X.Y.Z` и тег `vX.Y.Z`, отправит их на GitHub;
- создаст релиз с файлами `Planer-Setup-X.Y.Z.exe`, `Planer-X.Y.Z-portable.exe` и `SHA256SUMS.txt`.

Если тесты или сборка не прошли, номер версии откатывается и на GitHub ничего не уходит.
Флаги: `--dry-run` — только проверки и текст релиза, `--draft` — релиз-черновик (публикуется кнопкой на GitHub).

Обычная отправка кода без выпуска версии — `git push`. На GitHub при каждой отправке в `main` запускаются проверки
(типы и модульные тесты, `.github/workflows/ci.yml`).

## Проверки

```
npm test                 # всё: проверка типов, модульные тесты и автотесты Playwright (≈2 мин)
npm run typecheck        # проверка типов без сборки (tsc + JSDoc): main.js, preload.js, lib/, src/core.js
npm run test:unit        # модульные тесты логики (node --test tests/unit): даты, поиск, таймеры, резервные копии — секунды
npm run test:e2e         # автотесты Playwright для Electron, скриншоты пишутся в tests/screens/
npm run dist:dir
npm run test:packaged    # проверка собранного dist/win-unpacked/Planer.exe и сквозной тест
```

`test:packaged` сначала проверяет настоящий `Planer.exe` (`scripts/packaged-check.js`): включена защита (fuses),
программа запускается, `ELECTRON_RUN_AS_NODE` не работает, изменённый `app.asar` не запускается.
Затем делает копию `dist/win-unpacked-e2e`, где разрешён только отладчик (через него Playwright управляет программой),
и прогоняет на ней сквозной тест. Настоящая сборка при этом не меняется.

Тесты используют временные папки данных (переменная `PLANER_DATA_DIR`) и не трогают ваши настоящие данные.
Тестовые файлы (картинки, короткое видео WebM) генерируются автоматически в `tests/.fixtures/`.
Чтобы прогнать сквозной тест на другой сборке: `PLANER_EXE=<путь к Planer.exe> npx playwright test --project=packaged`
(у такой сборки отладчик должен быть разрешён).

## Сегодня и Неделя (календарь)

Каждая задача относится к конкретному дню (или лежит в «Без даты»).

- **Сегодня** — задачи сегодняшней даты: то, что вы расписали на этот день во «Неделе», плюс то, что добавили прямо здесь.
  Если в прошлые дни остались невыполненные задачи, внизу появится блок «Не сделано в прошлые дни»:
  каждую можно перенести на сегодня кнопкой со стрелкой (или все сразу). После полуночи колонка сама переходит на новый день.
- **Неделя** — календарь месяца (листайте месяцы стрелками ‹ ›) и под ним дни выбранной недели (‹ › — соседние недели).
  На обзоре видны **только срочные задачи** — с приоритетом `!!!`; у остальных дней показано, сколько там задач.
  Кнопка с флажком переключает «только срочные / все задачи», кнопка с календарём прячет сетку месяца,
  кнопка с солнцем возвращает к текущей неделе. Точка под числом — в этот день есть задачи, красная — есть срочные.
- **Щелчок по дню** (в сетке месяца или в списке недели) открывает окно дня со всеми задачами: их можно добавлять,
  менять, отмечать, менять порядок перетаскиванием. `Alt+←` / `Alt+→` — соседние дни, `Esc` — закрыть.
- Срочность задаётся флажком приоритета (щелчок перебирает `!` → `!!` → `!!!`) или `!!!` в конце текста новой задачи.
- Перенос задачи: меню `…` → «на сегодня», «на завтра», «на другой день…» (выбор в календаре) или «убрать дату».
  Любой перенос на другой день можно отменить.

### Перетаскивание мышью

Задачу можно взять мышью за любое место строки (за текст, за пустое место или за ручку слева) и перетащить:
поменять порядок, положить в блок времени или вынуть из него, бросить на день в списке недели или на число в календаре.
Пока задача «летит», синяя линия показывает, куда она встанет. `Esc` — отменить перетаскивание.
Если вы печатаете в задаче (курсор в тексте), мышь выделяет текст, а не переносит задачу.
На сенсорном экране задача перетаскивается только за ручку слева.

### Несколько задач сразу

`Ctrl`+щелчок по задаче добавляет её к выделению (или убирает), `Shift`+щелчок выделяет все задачи подряд до неё в том же списке.
Внизу появляется панель: **Выполнено**, **Приоритет**, **На сегодня**, **На завтра**, **На день…**, **Удалить**.
Перетащите любую выделенную задачу — переедут все выделенные, в том же порядке (на ярлыке видно их число).
Каждое такое действие — один шаг отмены. `Esc` или щелчок мимо снимает выделение.

### Блоки времени (по желанию)

День можно разбить на свои блоки, например **10:00 – 12:00 «Работа»** и **12:00 – 18:00 «Дела»**:
каждый блок — цветной прямоугольник со своими задачами, порядок — по времени начала.

- Создать: кнопка с часами в шапке «Сегодня» (или «…» → «Добавить блок времени»), в окне дня — кнопка «Блок времени».
  Укажите «с … до …» (24 часа; конец должен быть позже начала), необязательное название и один из 6 цветов.
- Если на день блоков ещё нет, в окне создания есть кнопка «Взять блоки из <прошлого дня>» — повторить вчерашнюю разметку одним щелчком.
- Задачи в блок: перетащить мышью, кнопка `+` в шапке блока (можно ввести несколько подряд) или меню задачи `…` → «В блок …».
  Задачи без блока показываются вверху, под заголовком «В любое время».
- Блок, который идёт прямо сейчас, отмечен «сейчас». Срочная задача из блока видна в обзоре недели со временем начала блока.
- `…` в шапке блока: изменить время, название и цвет или удалить блок — задачи при этом остаются в дне (удаление можно отменить).
- Блоки принадлежат конкретному дню: задача, перенесённая на другой день, выходит из блока.

## Таймеры для фокусировки

Кнопка с часами в **левом углу шапки** (рядом с «Планер»). Таймеры не привязаны к задачам — это для вас:
поработать сосредоточенно, сделать перерыв.

- Готовые шаблоны: «Фокус» 25 мин, «Короткий перерыв» 5 мин, «Длинный перерыв» 15 мин, «Глубокая работа» 50 мин.
  Свои — в форме «Новый таймер»: название и длительность (`25`, `1:30`, `1ч 30м`, `45 сек` — до 24 часов).
  Шаблоны можно менять и удалять (удаление отменяется кнопкой в уведомлении).
- `▶` запускает. Можно запустить несколько сразу (до 10). У идущего: пауза, `+1` минута, остановка.
  Пока таймер идёт, на кнопке в шапке видно оставшееся время.
- В конце — звук (колокольчик, мягкий, будильник или короткий сигнал; громкость и число повторов — в панели),
  сообщение «время вышло» с кнопками «Ещё 5 мин», «Повторить», «Готово» и уведомление Windows.
- Отсчёт идёт в основном процессе программы, поэтому он точный и звук прозвучит, даже когда окно свёрнуто в трей.
  После выхода из программы идущие таймеры не сохраняются.
- Запустить таймер можно и из меню значка в трее, и из мини-окна «Сегодня».

## Инструменты моушн-дизайнера

Кнопка **«Моушн»** рядом с таймером (или меню «Таймеры», или поиск). Вкладки:

- **Ссылки** — ваши сайты плиткой, открываются в браузере одним щелчком. Для начала там набор: aescripts, School of Motion,
  Motionographer, Behance, Dribbble, LottieFiles, Adobe Color, Google Fonts, Envato Elements, Pinterest.
  «Изменить» — убрать лишние, внизу — добавить свои. Список хранится вместе с данными и входит в резервные копии.
- **Экспрешены AE** — 14 шаблонов с настройками: wiggle (с осями и seed), loop, инерция (overshoot), отскок, вращение,
  покадровость (stop motion), следование с задержкой и каскад, счётчик чисел, печатная машинка, обратный отсчёт, мигание,
  поворот к слою, толщина обводки при масштабе, связь с ползунком. У каждого — куда вставлять и кнопка «Копировать».
  Нет нужного — опишите словами, и ассистент напишет экспрешн; код в ответе тоже копируется кнопкой.
- **Тайминг** — частота кадров, перевод кадры ↔ секунды ↔ таймкод (ЧЧ:ММ:СС:КК), под музыку: сколько кадров в доле и такте при заданном BPM.
- **Цвет** — пипетка или HEX / RGB / массив AE: показывает все записи, в том числе `[r, g, b, 1]` для экспрешена.
- **Форматы** — размеры кадра (Full HD, 4K, 9:16 для Reels и Shorts, 4:5, 1:1 и др.) с копированием и подсчёт соотношения сторон.

## Поиск по всему (Ctrl+K)

`Ctrl+K` или поле «Поиск» в шапке. Ищет по задачам за все дни (и по заметкам к ним), по блокам времени,
папкам, названиям и тексту страниц, по карточкам досок (заметки, чек-листы, ссылки, подписи к фото).
Регистр и «ё/е» не важны; если слов несколько, должны найтись все.

- `↑` `↓` — выбор, `Enter` — открыть: задача на сегодня — подсвечивается в «Сегодня», на другой день — открывается этот день,
  страница — открывается с выделенным найденным словом, карточка — доска открывается и показывает карточку.
- Можно ввести дату (`25.12`, `25.12.2026`, `завтра`, `вчера`) — откроется этот день.
- Быстрые действия: новая задача, новый документ или доска, таймеры, тема, компактный режим, восстановление из копии.

## Оформление

«Настройки» (шестерёнка в шапке) или меню «Вид»:

- **Тема:** как в системе, светлая или тёмная.
- **Размер интерфейса:** 80–150 % (`Ctrl` + `=` / `−` / `0`, или `Ctrl` + колесо вне доски).
- **Компактный режим:** плотнее строки и отступы — помещается больше задач.

Настройки сохраняются и применяются и к мини-окну.

## Резервные копии и восстановление

Каждый день Планер сам копирует все данные (`backups\docs-ГГГГ-ММ-ДД`, хранятся 14 последних). Если программа
неделями работает в трее, копия всё равно делается каждый день. Дополнительно можно сделать копию кнопкой «Сделать копию сейчас».

**Восстановить:** «Настройки → Восстановить из копии…» (или меню «Данные», или поиск).
Слева — копии по дате, справа — что в выбранной копии и чем она отличается от текущих данных:
календарь (сколько задач тогда и сейчас), «Основные планы», «Идеи», таймеры и каждая доска отдельно.
Можно вернуть что-то одно или всё отличающееся; кнопка срабатывает со второго нажатия («Точно восстановить?»).

- Перед восстановлением текущие данные сохраняются в копию «Перед восстановлением». Поэтому восстановление можно
  отменить кнопкой в уведомлении или позже, выбрав эту копию.
- Восстановленное сразу видно в программе, перезапуск не нужен. Документы, которых не было в копии
  (например, доски, созданные позже), не трогаются.

## Файлы: текстовые документы и доски

В колонках **«Основные планы»** и **«Идеи»** каждый файл — либо **текстовый документ**, либо **доска**:

- Иконка показывает тип: лист бумаги — текст, цветной холст — доска (рядом число карточек).
  Под заголовком колонки — сколько всего текстов и досок.
- **Двойной щелчок по названию** сразу открывает файл: текст — в редакторе, доска — холстом.
  Одиночный щелчок только выделяет строку; `Enter` открывает выделенный файл, `F2` — переименовать.
- Создать: кнопка «Новый файл» в шапке колонки (или `+` у папки) → «Текстовый документ» или «Доска».
- Сменить тип: меню `…` файла → «Сделать доской» / «Сделать текстовым документом». Содержимое не теряется:
  текст и доска хранятся отдельно, и к прежнему содержимому можно вернуться (пункты «Открыть прежнюю доску / прежний текст»).
- Старые страницы, у которых была только доска (без текста), автоматически стали досками.

### Текстовые документы — как в Notion

Документ — одно сплошное поле: текст выделяется мышью через любые строки, `Ctrl+A` выделяет всё, копировать и удалять можно сразу много.

- **Блоки:** текст, заголовки 1–3, задача (чекбокс), маркированный и нумерованный списки, цитата, выноска (со значком), код, разделитель.
- **«/»** в начале строки или после пробела — меню блоков; набирайте название («заг», «код», «выно»), `Enter` — выбрать.
- **Как в Markdown:** `# ` `## ` `### ` — заголовки, `- ` — список, `1. ` — нумерованный, `[] ` — задача, `> ` — цитата,
  ` ``` ` — код, `---` — разделитель. `Tab` / `Shift+Tab` — вложенность списков.
- **Выделите текст** — появится панель: жирный (`Ctrl+B`), курсив (`Ctrl+I`), подчёркнутый (`Ctrl+U`), зачёркнутый (`Ctrl+Shift+S`),
  код (`Ctrl+E`), ссылка (`Ctrl+K`), убрать оформление. Ссылка открывается по `Ctrl`+щелчку.
- **Ручка «⋮⋮»** слева от строки: перетащите — блок переедет; щелчок — меню (превратить в другой блок, дублировать, выше/ниже, удалить).
  «+» рядом — новый блок ниже. `Alt+↑/↓` — переместить блок, `Ctrl+D` — дублировать, `Ctrl+Alt+0…9` — сменить тип.
- Задача отмечается щелчком по квадратику (или `Ctrl+Enter`), значок выноски меняется щелчком по нему.
- Копирование нескольких блоков даёт текст в Markdown (списки, заголовки и задачи сохраняются), вставка Markdown превращается в блоки.
  «…» → «Копировать как Markdown» — вся страница.
- `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор. Первый `Esc` снимает выделение, второй закрывает страницу.

## Доска

Слева — панель добавления: **Заметка, Чек-лист, Рисовать, Фото / видео, Зарисовка, Ссылка**. Ещё способы:
двойной щелчок по пустому месту (заметка), перетаскивание файлов из проводника (карточка появится там, куда бросили;
несколько файлов раскладываются сеткой), `Ctrl+V` (скриншот, скопированная картинка, ссылка или текст).

В заметках: `**жирный**`, строка с `- ` — список, `[ ] ` — чекбокс (отмечается щелчком прямо на доске).
Панель форматирования и цвета появляется сверху, пока заметка редактируется.

**Ссылки с описанием.** Вставленная ссылка (`Ctrl+V`, кнопка «Ссылка» или перетаскивание из браузера) сама подтягивает
заголовок, описание и картинку-превью сайта; у YouTube — название ролика, описание, канал и обложку с кнопкой воспроизведения.
Для этого программа один раз загружает страницу (только `http/https`, без адресов локальной сети, с ограничением времени и размера);
картинка сохраняется в `media/`, дальше карточка показывается и без интернета. Уже добавленные ссылки получают превью
при открытии доски. Свой заголовок можно задать в «Редактировать» — он заменит заголовок сайта.

### Горячие клавиши доски

| Действие | Клавиши |
|---|---|
| Рамка выделения | протянуть по пустому месту; с `Shift` или `Ctrl` — добавить к выделению |
| Перемещение холста | `Пробел` + мышь, средняя кнопка, колесо / тачпад; инструмент «Рука» (`H`) — протягиванием |
| Инструменты | `V` — выделение, `H` — рука (кнопки в правом нижнем углу) |
| Масштаб | `Ctrl` + колесо, `+` / `−`, `Shift+0` — 100 %, `Shift+1` — показать всё |
| Выделить несколько / всё | `Shift` или `Ctrl` + щелчок, `Ctrl+A` |
| Без притяжения | держать `Alt` при перетаскивании |
| Редактировать | двойной щелчок, щелчок по выделенной заметке, `Enter` |
| Новая заметка | двойной щелчок по пустому месту, `N` |
| Удалить | `Delete` / `Backspace` (можно отменить) |
| Дублировать | `Ctrl+D` |
| Копировать / вырезать / вставить | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` (или `Ctrl+Y`), до 100 шагов |
| Сдвинуть выделенное | стрелки (10 px), `Shift` + стрелки (1 px) |
| Рисовать от руки | `P` (включить / выключить), в режиме рисования: `B` — перо, `M` — маркер, `E` — ластик |
| Закрыть доску / выйти из редактирования | `Esc` или щелчок по затемнённому фону |

**Выравнивание.** Когда выделено две карточки и больше, сверху появляются кнопки: по левому, правому краю и по центру,
по верхнему, нижнему краю и по середине; для трёх и больше — «Распределить» (равные промежутки по горизонтали или вертикали);
«Разложить аккуратной сеткой». При перетаскивании карточки притягиваются к краям и центрам соседних — видна розовая направляющая;
держите `Alt`, чтобы двигать без притяжения.

**Ассистент на доске** умеет навести порядок: «разложи по темам», «выровняй», «добавь ссылку на …», «сделай заметки про свет жёлтыми».
Он переставляет и меняет размер карточек, раскладывает их сеткой или колонками по типу, меняет текст и цвет, добавляет заметки,
чек-листы и ссылки; удаляет — только если прямо попросить. У каждого действия в чате кнопка «Вернуть как было»
(она возвращает только это действие), а на открытой доске работает и `Ctrl+Z`.

Правый щелчок по карточке — меню: цвет, слои (на передний/задний план), подпись, «Нарисовать поверх»,
«Сохранить как…» (PNG), «Копировать в буфер», «Открыть во внешнем плеере» (для видео).
Двойной щелчок по фото — просмотр во весь экран (колесо — масштаб, `←` `→` — соседние фото, `0` — вписать).

### Рисование от руки прямо на доске

Кнопка **«Рисовать»** (или `P`) — и можно рисовать что угодно прямо на холсте, поверх и между карточками.
Сверху появляется панель: перо, маркер (полупрозрачный и толще), ластик; шесть цветов (чёрный подстраивается под тему),
три толщины, «Готово» (или `Esc`).

- Штрихи, нарисованные рядом друг с другом, собираются в один **рисунок**. Это обычная карточка: её можно выделить
  щелчком по линии, двигать, менять размер без искажения, копировать, удалять, класть на передний или задний план,
  сохранить как PNG. Пустые места рисунка не мешают щёлкать по карточкам под ним.
- Ластик стирает штрихи, которых касается. Всё отменяется `Ctrl+Z`.
- Масштаб и перемещение холста работают и во время рисования (`Ctrl` + колесо, `Пробел` + мышь, средняя кнопка).
- Ассистент видит рисунки на доске и может посмотреть на них, если попросить.

### Зарисовки

Зарисовка — отдельная карточка-холст со своим редактором (фигуры, текст, фон). Инструменты: перо (с нажимом пера/стилуса), маркер, ластик (по штрихам или «по пикселям»), линия, стрелка,
прямоугольник, эллипс, текст, пипетка. Фон: прозрачный, белый, клетка, линейка.
Клавиши: `P` `M` `E` `L` `A` `R` `O` `T` `I` — инструменты, `[` `]` — толщина, `Shift` — ровные линии и фигуры,
`Ctrl+Z` / `Ctrl+Shift+Z`, `Пробел` или средняя кнопка — перемещение, `Ctrl` + колесо — масштаб.
`Esc` или «Готово» — сохранить и закрыть, «Отмена» — закрыть без изменений.
Рисунок поверх фото хранится отдельным слоем: оригинал не меняется, слой можно убрать в меню карточки.

### Поддерживаемые форматы

- Изображения: PNG, JPG/JPEG, WEBP, GIF (анимация сохраняется), AVIF, SVG.
- Видео: MP4 (H.264), WEBM, MOV, MKV. Если кодек не поддерживается встроенным плеером (например, HEVC/H.265
  на некоторых компьютерах), карточка покажет сообщение и кнопку «Открыть во внешнем плеере».
- Предел одного файла — 2 ГБ; для файлов больше 200 МБ показывается прогресс копирования.
- HEIC/HEIF не поддерживается (сохраните фото как JPG).

## Где что лежит

Кратко: **программа** — в `%LOCALAPPDATA%\Programs\Planer\` (или там, где лежит portable-файл),
**ваши данные** — в `%APPDATA%\Planer\`, **исходники и сборки** — в папке проекта.

### 1. Установленная программа (после `Planer-Setup-<версия>.exe`)

| Что | Где (по умолчанию) |
|---|---|
| Папка программы | `%LOCALAPPDATA%\Programs\Planer\` (например, `C:\Users\<имя>\AppData\Local\Programs\Planer\`); если при установке выбрана другая папка — там |
| Запускаемый файл | `…\Planer\Planer.exe` |
| Код приложения (упакован) | `…\Planer\resources\app.asar` |
| Удаление программы | `…\Planer\Uninstall Planer.exe` (или «Параметры → Приложения») |
| Ярлык на рабочем столе | `Рабочий стол\Планер.lnk` |
| Ярлык в меню «Пуск» | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Планер.lnk` |
| Запись для «Программы и компоненты» | реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<GUID>` |

Установщик ставит программу только для текущего пользователя, в системные папки (`Program Files`) ничего не пишет.
При удалении стираются папка программы, ярлыки и запись в реестре; **данные в `%APPDATA%\Planer\` остаются**
(чтобы удалить всё, сотрите эту папку вручную при закрытой программе).

### 2. Portable-версия (`Planer-<версия>-portable.exe`)

Один файл, лежит там, куда вы его положили. При каждом запуске он распаковывается во временную папку
`%TEMP%\<служебное имя>\` и удаляет её после выхода. Данные хранит **в той же папке `%APPDATA%\Planer\`**,
что и установленная версия, поэтому одновременно может работать только одна из них.

### 3. Ваши данные

- Windows: `%APPDATA%\Planer\` (например, `C:\Users\<имя>\AppData\Roaming\Planer\`)
- macOS: `~/Library/Application Support/Planer/`
- Linux: `~/.config/Planer/`

## ИИ-ассистент

Два способа подключения (меню «Ассистент» или подпись под заголовком панели ассистента):

**Подписка Claude (по умолчанию, если не сохранён ключ API).** Ассистент работает через Claude Code на этом компьютере,
запросы идут в счёт лимитов вашей подписки Claude (Pro/Max) — платить за API не нужно.
- Claude Code уже входит в приложение Claude для Windows (Планер сам находит `%LOCALAPPDATA%\Claude-Data\…\claude.exe`),
  либо ставится отдельно (`claude` в PATH или `%USERPROFILE%\.local\bin\claude.exe`). Другое место — кнопка «Указать claude.exe…».
- Один раз войдите: меню «Ассистент → Подключение и вход в Claude…» → «Войти в Claude». Откроется окно консоли и браузер —
  войдите в свой аккаунт Claude с подпиской; окно подключения само увидит, что вход выполнен.
  То же вручную: `claude auth login --claudeai`.
- Модель: Sonnet (по умолчанию, быстрее), Opus (умнее, расходует больше лимита) или Haiku — в том же окне.
- Как это устроено: на каждый шаг Планер запускает `claude -p` без встроенных инструментов Claude Code
  (`--tools ""`, без MCP, без пользовательских настроек и хуков, без сохранения сеанса) в пустой папке `claude-work`.
  Модель отвечает JSON-ом `{reply, tool_calls}`, инструменты Планера выполняет само приложение.
  Ключи API из окружения в Claude Code не передаются, чтобы запросы не ушли в платный API.
- Лимиты общие с claude.ai и Claude Code. Ответ приходит медленнее, чем через API: каждый шаг — новый запуск Claude Code.

**Ключ API Anthropic.** Запросы к api.anthropic.com с вашим ключом, оплата по тарифам API
(создать ключ: https://console.anthropic.com/settings/keys). Ключ хранится только на этом компьютере и уходит
только на api.anthropic.com из основного процесса. Сменить или удалить ключ: меню «Ассистент».

Ассистент видит календарь (сегодня, неделю назад и 4 недели вперёд, «Без даты») и умеет добавлять задачи на любой день,
менять их, переносить между днями и удалять (удаляет только по прямой просьбе), читать, создавать и переписывать страницы
(заголовки, списки, задачи, цитаты, выноски, код), **читать доски страниц** и **наводить на них порядок**:
переставлять и менять размер карточек, раскладывать сеткой, колонками по типу или в ряд, менять текст и цвет,
добавлять заметки, чек-листы и ссылки (в свободное место), удалять карточки — только по прямой просьбе.
У каждого изменения доски или страницы в чате есть кнопка «Вернуть как было» — она отменяет только это действие.
Код в ответах (например, экспрешены After Effects) показывается отдельным блоком с кнопкой «Копировать».
Картинки с досок он видит только когда вы прямо просите посмотреть: изображение уменьшается до 1568 px и
отправляется в формате JPEG; в чате видно, какие картинки отправлены. Модели для ключа API задаются в `shim.js` (`MODELS`).

## Из чего состоит

- `index.html` — разметка главного окна; код приложения — `src/app/*.js` (обычные скрипты по порядку подключения:
  `base` — помощники и модель, `store` — сохранение, `columns`/`drag`/`select`/`calendar` — задачи (`select` — выделение нескольких),
  `tree`/`editor` — страницы (`editor` — блочный редактор как в Notion), `ai` — ассистент, `timers`, `tools` — «Моушн»,
  `search`, `settings`, `mini-host`, `boot` — запуск). Встроенного кода в HTML нет. Имена верхнего уровня в этих файлах
  общие, поэтому повторяться не должны — это проверяет `tests/unit/globals.test.js`.
- `src/core.js` — чистая логика без окна: даты, проверка данных, разбор ввода, поиск, таймеры, блоки страниц и Markdown
  (её проверяют модульные тесты). `src/motion.js` — шаблоны экспрешенов After Effects, кадры и таймкод, цвет, форматы кадра.
- `src/board.js`, `src/board.css` — доска страницы (включая рисование от руки); `src/sketch.js` — редактор зарисовок.
- `mini.html`, `src/mini.js` — мини-окно «Сегодня». `shim.js` — подменяет хранилище и ИИ-часть на локальные.
- `main.js` — окна, меню, трей, оформление, автозапуск, ключ, запросы к API; `lib/timers.js` — таймеры;
  `lib/backups.js` — резервные копии и восстановление; `lib/claudecode.js` — запуск Claude Code (подписка Claude);
  `lib/linkpreview.js` — превью ссылок; `lib/store.js` — документы, миграция, ежедневные копии;
  `lib/media.js` — медиа, схема `media://`, миниатюры, сборка мусора; `preload.js` — мост к странице.
- `tests/` — автотесты Playwright и модульные тесты, `scripts/make-icon.js` — иконка, `scripts/packaged-check.js` — проверка сборки.

### Безопасность сборки

- Окна изолированы (`contextIsolation`, `sandbox`), в CSP скрипты только из файлов программы (`script-src 'self'`, без `'unsafe-inline'`).
- В `Planer.exe` включены защитные флаги Electron (fuses): программу нельзя запустить как Node.js (`ELECTRON_RUN_AS_NODE`),
  нельзя подключить отладчик (`--inspect`) или подсунуть `NODE_OPTIONS`; код загружается только из `app.asar`,
  и его целостность проверяется при запуске (изменённый `app.asar` не запустится); куки шифруются.
- В сборку входят только русская и английская локали Chromium — установщик меньше примерно на 8 МБ.

## Известные ограничения

- Описание ссылки берётся из данных, которые сайт отдаёт для превью (Open Graph); если сайт их не даёт или требует входа,
  карточка покажет только домен и заголовок. Обновить вручную: меню карточки → «Обновить описание и превью».
- Доска удалённой страницы не стирается: её файл остаётся в `docs/` (это позволяет отменить удаление),
  а медиа с такой доски не стираются автоматически.
- Блок «Не сделано в прошлые дни» охватывает последние 60 дней; более старые задачи остаются на своих датах в календаре.
- Видео с HEVC и некоторыми другими кодеками может не воспроизводиться встроенным плеером — используйте внешний.
- Анимированный GIF на доске показывается оригиналом (без уменьшенной копии).
- Один экземпляр программы на одну папку данных; синхронизации между компьютерами нет.
- Установщик и программа не подписаны (предупреждение SmartScreen при первом запуске): для подписи нужен
  платный сертификат разработчика.
- Идущие таймеры не переживают выход из программы (шаблоны и настройки звука сохраняются).
- Проверка типов (`npm run typecheck`) охватывает основной процесс, мост, `src/core.js` и `src/motion.js`;
  код окна (`src/app/*.js`) пока не типизирован.
- Текстовые страницы хранят простое оформление (жирный, курсив, подчёркнутый, зачёркнутый, код, ссылки);
  таблиц, картинок и вложенных страниц внутри текста нет — для этого есть доски.
